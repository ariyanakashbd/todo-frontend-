# TaskFlow - Todo Management Frontend

## Run the project
1. Install Node.js (version 18 or newer)
2. Open a terminal in this folder
3. `npm install`
4. `npm run dev`
5. Open http://localhost:5173

## Pages
/ (Home), /login, /register, /dashboard

## Backend later
- Set your URL in `src/services/api.js`
- Replace the `YOUR_..._ENDPOINT` placeholders in `authService.js` and `taskService.js`
- Follow the `TODO (backend)` comments in Login.jsx, Register.jsx, Sidebar.jsx and DashboardHome.jsx
